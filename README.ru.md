# 2pack

[English](README.md) · **Русский**

Крошечный бинарный кодек со схемой для Node и браузеров. Пакет описывается один раз на TypeScript: тип выводится сам, байтов мало, а при разборе враждебных данных можно получить только один вид ошибки. Без зависимостей, без кодогенерации, буферами владеете вы.

> Версия 2 — переписанная с нуля и **несовместима с 1.x**: порядок полей, префиксы размеров и весь API изменились.

## Стек

TypeScript 6, только ESM, ноль зависимостей в рантайме, Node 18+ и любой современный браузер. Тесты на vitest.

## Быстрый старт

```ts
import { array, define, enumOf, i16, quant, str, u8, varuint, type Infer } from '@1337exp/2pack';

const Packet = define({
    kind: enumOf(['join', 'move', 'chat']),
    name: str(16), // не больше 16 байт UTF-8; длиннее — ошибка, без обрезки
    hp: i16,
    pos: define({ x: quant(-500, 500, 16), y: quant(-500, 500, 16) }), // по 2 байта, ошибка меньше 0,008
    items: array(define({ id: varuint, count: u8 }), 8),
});

type Packet = Infer<typeof Packet>; // { kind: 'join' | 'move' | 'chat'; name: string; hp: number; ... }

const bytes = Packet.pack({ kind: 'move', name: 'D', hp: -13, pos: { x: 12.5, y: -3 }, items: [{ id: 7, count: 2 }] });
const value = Packet.unpack(bytes); // с типом и проверкой, либо PackError
```

Несколько пакетов в одном буфере (заголовок, потом данные), без аллокаций:

```ts
const Header = define({ type: u8, version: u8 });
const Hello = define({ name: str(16), hp: i16 });
const buf = new Uint8Array(Header.max + Hello.max);

let n = Header.packInto(buf, { type: 3, version: 1 });
n += Hello.packInto(buf, { name: 'D', hp: 100 }, n);

const [header, at] = Header.unpackAt(buf, 0, n);
const payload = Hello.unpack(buf, at, n);
```

## Типы

| | |
|---|---|
| `bool` `u8` `i8` `u16` `i16` `u32` `i32` `f32` `f64` | фиксированный размер, little-endian |
| `u64` `i64` | 8 байт, `bigint` |
| `varuint` `varint` | от 1 до 5 байт, малые числа занимают один байт |
| `str(maxBytes)` `bytes(maxBytes)` | с префиксом длины, максимум обязателен |
| `array(item, maxCount)` `optional(item)` `enumOf([...])` | |
| `quant(min, max, bits)` | число из известного диапазона в 8, 16 или 32 битах |
| `define({...})` | запись, поля в порядке объявления, имена не передаются |

У каждого типа переменного размера объявлен максимум, поэтому у любого кодека конечные `min` и `max`: `new Uint8Array(codec.max)` всегда вмещает значение.

Формат на уровне байтов описан в [docs/spec.md](docs/spec.md), эталонные байты в `tests/vectors.ts`.

## Буфер ваш

Три способа упаковки и страница, которая объясняет почему:

| | аллокации | байты |
|---|---|---|
| `pack(value)` | одна на пакет | ваши навсегда (по умолчанию, всегда безопасно) |
| `packInto(buf, value, offset?)` | нет | в **вашем** буфере |
| `packShared(value)` | нет | окно, следующий вызов его перезапишет |

Отдать окно от `packShared` в `socket.write()` — настоящая ошибка при backpressure: [Чьи это байты](docs/buffer-ownership.ru.md) показывает, как она случается, и объясняет. `npm run backpressure` воспроизводит её у вас на машине.

## Безопасно по построению

- Ничего не заворачивается и не обрезается: `300` в `u8`, `1.5` в `u16`, `NaN` в `i32` и строка длиннее лимита — ошибки с указанием места (`players[3].hp`).
- Разбор никогда не читает за пределами `[offset, end)` и сверяет каждую длину и с объявленным максимумом, и с оставшимися байтами. Миллиард элементов в десятибайтовом пакете отклоняется до всякого выделения памяти.
- Враждебные и битые байты дают `PackError` и ничего другого: проверено тестами с обрезанием каждого пакета на каждую длину и 40 000 случайных порч.
- Результаты — обычные объекты, которые владеют своими данными. `packInto` пишет только байты пакета.

## Скорость и размер

Одна машина (Node 22, Windows), мелкие объекты, медиана из 5 прогонов. Воспроизводится `npm run bench`. Сравнение по безопасному `pack`, который копирует.

| | размер | кодирование | разбор |
|---|---|---|---|
| **2pack**, запись 24 байта | **24 Б** | **108 нс** | **144 нс** |
| msgpackr | 57 Б | 217 нс | 195 нс |
| cbor-x | 58 Б | 205 нс | 334 нс |
| JSON (в байтах) | 70 Б | 442 нс | 763 нс |
| **2pack**, снимок из 20 юнитов | **144 Б** | **1246 нс** | **1265 нс** |
| msgpackr | 608 Б | 2164 нс | 3607 нс |
| cbor-x | 634 Б | 2554 нс | 3740 нс |
| JSON (в байтах) | 792 Б | 3849 нс | 4767 нс |

Выигрыш в размере структурный: когда схема есть у обеих сторон, имена и теги типов не передаются. Если схемой поделиться нельзя, берите msgpackr или cbor-x: они хороши.

## Пока нет

- **Эволюции схемы.** Пакет читается только той схемой, которой записан. Версию кладите в небольшой кодек-заголовок (см. спецификацию).
- **Второй реализации.** Формат описан по байтам, чтобы на другом языке можно было реализовать, но существует только TypeScript.
- **Сборки CommonJS.** Только ESM; Node 22 умеет `require()` для него.
